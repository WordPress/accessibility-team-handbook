# Accessibility Team Handbook

This is the repository for the [WordPress Accessibility Team Handbook](https://make.wordpress.org/accessibility/handbook/).

## Contributing

- **Discuss**: Conversations and discussions take place in the [#accessibility channel](https://wordpress.slack.com/archives/C02RP4X03) on the [Making WordPress Slack](https://make.wordpress.org/chat/).
- **Contribute**: Additions and changes to the Accessibility Team Handbook happen in the GitHub repo. Get started by reading the [contributing guidelines](CONTRIBUTING.md).
